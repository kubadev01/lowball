# lowball

[![CI](https://github.com/kubadev01/lowball/actions/workflows/ci.yml/badge.svg)](https://github.com/kubadev01/lowball/actions/workflows/ci.yml)

This project is a free command-line tool written in Python that allows users to track the prices of products they wish to purchase, so they can buy at the right time.

Planned features:

- support for multiple stores
- price history
- automated price checking
- notifications when a product's price drops below a set level
